# Student Marks Analysis

A simple Python project to analyze student marks and performance.

## Features
- Calculates total, average marks, and grades
- Finds top and weak students
- Shows subject-wise performance
- Creates charts using Matplotlib and Seaborn

## Tech Stack
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
`students.csv` contains student ID, name, gender, subject marks, and attendance.

## How to Run

```bash
pip install pandas matplotlib seaborn
python marks_analysis.py
```
